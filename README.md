# AI PM Student Script Coach

面向 AI 产品经理学员的简历面试准备 skill。先从简历和项目材料生成 **50 道有深度的主问题**；学员看过并确认方向后，再按题号分批解释每题考什么、怎样组织回答，并给出基于真实经历的口头参考回答。

本 skill 服务于**学员备考**。面试官现场使用的追问链、变化情境、评分和录用判断属于单独的 `interview-designer-1.0.0`，不会进入学员材料。

## 两阶段工作流

### 第一阶段：50 道主问题

输入简历；有 PRD、作品集、项目总结或目标 JD 时一起提供。输出只包含 `Q01`–`Q50` 的题号与主问题，不展示维度码、评分、参考答案或证据台账。题目会结合候选人的经历，内部检查 Interview Designer 的 A–K 能力域覆盖。

技术题从具体业务任务出发，覆盖适用的数据与多模态处理、RAG/检索、Prompt 与模型选择、Workflow、评测、Bad Case、延迟与成本、安全、灰度和运行维护。它们问产品判断和验证依据，不要求学员冒充算法工程师。

输出 50 题后，skill 会停下来请学员审阅。学员可以调整题目方向或指定要展开的题号。

### 第二阶段：确认后分批细化

收到确认后，沿用第一阶段的题号和题干，通常每批细化 4–6 题。每题包括：

1. **这个问题在考什么**：与简历主张相关的能力和判断。
2. **回答模型**：针对该题的表达路径，例如事实与贡献、方案取舍、指标解释或故障处理。
3. **参考回答**：可口述的第一人称初稿，供学员结合本人事实修改。

简历没有证明的个人经历、数字口径或项目阶段不会被编造成事实。如果用户明确要求跳过审阅、直接全量生成，可以连续完成两阶段。

## 使用示例

```text
$ai-pm-student-script-coach
这是我的简历。请先生成 50 道主问题，覆盖 AI 产品经理的主要能力域，技术题要结合我的项目问深。先只给题目，等我确认后再细化。
```

确认题目后：

```text
$ai-pm-student-script-coach
这 50 题可以。请从 Q01–Q05 开始，逐题说明考什么、回答模型和口头参考回答。
```

也可以指定题号、批量大小，或确认后要求把全部题目分批细化。

## 安装

将仓库克隆到 Codex 的 skills 目录：

```bash
git clone https://github.com/zhangchau/ai-pm-student-script-coach.git ~/.codex/skills/ai-pm-student-script-coach
```

若该目录已经存在，请先确认它是否为本仓库的 Git 检出；普通复制安装的目录不能直接运行 `git pull`。可以在其他目录克隆仓库，再将更新后的 skill 文件复制过去。

## 文件结构

```text
ai-pm-student-script-coach/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── coverage-model.md
    └── output-template.md
```

`coverage-model.md` 只用于内部检查题目覆盖；学员第一阶段看到的是简洁的 50 道主问题。

## 事实边界

参考回答基于学员提供的材料，不新增用户、客户、个人贡献、指标口径、上线阶段或业务结果。项目只有 PRD 或 Demo 时，应说明设计判断和验证计划；项目真实使用时，应以可核对的记录说明使用范围和结果。对目标公司与岗位的判断，需要提供目标 JD。
